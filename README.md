# Park Avenue Mens Wear — Maintenance & Payment Hold Notice

An official administrative notice page indicating that the website is under maintenance by Zentrixasr Websites with services temporarily placed on a payment hold.

## Features

- **Large Prominent Typography**: "Under Maintenance." in display serif format, with high-visibility "Payment On Hold" callout.
- **Rewritten in Clear Professional English**: Clear explanation of administrative hold and instructions for payment clearance.
- **Administrative Status Badges**: Pulsing warning indicators and an administrative review notice card.
- **Branding & Credits**: Park Avenue Mens Wear brand identity preserved with hosting and maintenance attribution to Zentrixasr Websites.
- **Responsive Layout**: Designed for seamless viewing across desktop and mobile devices.

## Tech Stack

- React 19
- TypeScript
- Vite
- Responsive CSS
